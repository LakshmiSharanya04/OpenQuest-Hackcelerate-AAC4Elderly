# 🗣️ Aalambana AAC

**Accessible Communication Support for Elderly Individuals**

Aalambana AAC is an Augmentative and Alternative Communication (AAC) application designed to help elderly individuals communicate their everyday needs, express feelings, and convey important messages through a simple, accessible, touch-based interface with voice output.

The application enables users to communicate by selecting predefined or personalized phrase cards, which are converted into speech using natural-sounding voice synthesis.

---

## 🎯 Project Objective

The primary objective of Aalambana AAC is to overcome communication barriers faced by elderly individuals, particularly those experiencing speech difficulties or age-related communication challenges.

The application aims to provide an accessible and user-friendly communication platform that promotes independence through instant voice output, categorized phrases, emergency communication, and personalized phrase management.

---

## 🚀 Key Features

- 🔊 **Tap-to-Speak Communication:** Instantly converts selected phrases into spoken audio without requiring additional confirmation.
- 🗂️ **Category-Based Communication:** Organizes phrases into six categories – Needs, Comfort, Medical, Feelings, Questions, and Responses.
- 💬 **Quick Starter Phrases:** Provides frequently used expressions such as "I want…" for faster communication.
- 🚨 **Emergency Communication:** A permanently visible urgent communication bar with four important emergency phrases for quick access.
- 🔁 **Last Spoken Phrase:** Displays the most recently spoken phrase with Replay and Stop controls.
- 🗣️ **Natural Voice Output:** Converts selected text into clear, natural-sounding speech to support effortless communication.
- 🌐 **Multilingual Communication:** Supports Telugu and English, with provision for additional languages.
- 👆 **Simple Touch Interface:** Features large, accessible phrase tiles for easy interaction.
- 🔠 **Adjustable Text Size:** Offers four display scaling levels (1.0x, 1.2x, 1.4x, and 1.6x) for improved readability.
- 💾 **Personalized Communication:** Allows caregivers to add, remove, hide, and restore custom communication phrases.
- 💿 **Persistent Preferences:** Saves language preferences, text scaling, hidden phrases, and custom phrases using browser Local Storage.

---

## ⚡ Application Workflow

1. The user opens the Aalambana AAC application.
2. The home screen displays communication categories and frequently used starter phrases.
3. The user selects a category or starter phrase.
4. Relevant communication phrases are displayed as large interactive tiles.
5. The user taps a phrase to trigger immediate voice output.
6. The selected phrase appears in the Last Spoken section.
7. The user can replay or stop the generated audio whenever required.
8. Caregivers can personalize communication by managing custom phrases, adjusting display settings, and configuring available preferences.
