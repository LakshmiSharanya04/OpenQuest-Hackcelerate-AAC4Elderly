# 🗣️ AAC Communication Assistant for Elderly People

An **Augmentative and Alternative Communication (AAC) application** designed to help elderly individuals communicate their everyday needs, express feelings, and convey urgent messages through a simple, accessible, touch-based interface with AI-assisted voice output.

The application enables users to communicate by selecting predefined or personalized phrase cards, which are converted into speech using natural-sounding voice synthesis.

---

## 🎯 Project Objective

The primary objective of this project is to overcome communication barriers faced by elderly individuals, particularly those experiencing speech difficulties or age-related communication challenges.

The application aims to provide an accessible and user-friendly communication platform that promotes independence through instant voice output, categorized phrases, emergency communication, and caregiver-assisted personalization.

---

## 🚀 Key Features

* 🔊 **Tap-to-Speak Communication:** Instantly converts selected phrases into spoken audio without requiring additional confirmation.
* 🗂️ **Category-Based Communication:** Organizes phrases into six categories – Needs, Comfort, Medical, Feelings, Questions, and Responses.
* 💬 **Quick Starter Phrases:** Provides frequently used expressions such as "I want…" for faster communication.
* 🚨 **Emergency Communication:** A permanently visible urgent communication bar with four important emergency phrases.
* 🔁 **Last Spoken Phrase:** Displays the most recently spoken phrase with Replay and Stop controls.
* 🗣️ **Natural Voice Output:** Converts selected text into clear, natural-sounding speech to support effortless communication.
* 🌐 **Multilingual Communication:** Supports Telugu and English, with provision for additional languages.
* 👆 **Simple Touch Interface:** Large, accessible phrase tiles designed for easy interaction.
* 🔠 **Adjustable Text Size:** Offers four display scaling levels to improve readability.
* 💾 **Personalized Communication:** Allows caregivers to add, remove, hide, and restore custom phrases.

---

## ⚡ Application Workflow

1. The user opens the AAC application.
2. The home screen displays communication categories and frequently used starter phrases.
3. The user selects a category or starter phrase.
4. Relevant communication phrases are displayed as large interactive tiles.
5. The user taps a phrase to generate immediate voice output.
6. The selected phrase appears in the Last Spoken section.
7. The user can replay or stop the generated audio whenever required.
8. Caregivers can access staff mode to personalize phrases, adjust settings, and manage communication options.

---

## 👨‍⚕️ Caregiver / Staff Mode

The application includes a dedicated caregiver interface for managing and personalizing the communication experience.

Caregiver functionalities include:

* Adding personalized communication phrases.
* Removing custom phrases.
* Hiding or restoring existing phrases.
* Adjusting text display size.
* Configuring language preferences.
* Previewing text-to-speech output.

**Access Mechanism:** Staff mode can be unlocked by tapping the settings gear icon four times within three seconds.
